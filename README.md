# WorldInu

The official concept site for WorldInu ($WINU), a Solana-native community ecosystem connecting Inu project discovery, verification, identity, and participation.

## Technology

- TanStack Start and React 19
- TypeScript
- Tailwind CSS 4 with custom responsive styling
- Lucide icons
- Netlify deployment adapter

## Local development

Install dependencies with `pnpm install`, then run `pnpm dev`. The production build command is `pnpm build`.

The primary experience lives in `src/routes/index.tsx`, global presentation is in `src/styles.css`, and shared metadata is configured in `src/routes/__root.tsx`.
